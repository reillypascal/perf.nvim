# perf.nvim

A Neovim color scheme written in Lua and based on Boris Zubarev's "[Warm Perf](https://zed-themes.com/themes/4zAKDuxDwoJpzLfp9QEYm?name=Warm%20Perf)" theme for Zed.

NOTE: this is a work in progress, and subject to change without notice!

Based on [this tutorial](https://medium.com/@ronxvier/build-your-own-neovim-colorscheme-in-lua-3b01adf019e0).
